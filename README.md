# 🏡 Nexter – Real Estate Landing Page

**Nexter** is a responsive landing page for a fictional high-end real estate company. Built with modern HTML and CSS, the project showcases advanced layout techniques like CSS Grid, Flexbox, and responsive design without using JavaScript or external libraries.

## 🧰 Technologies Used

- HTML5 (Semantic Structure)
- CSS3 (Custom Properties, Grid, Flexbox)
- BEM (Block Element Modifier) naming convention
- Responsive Design

## 🌟 Features

- Fully responsive grid-based layout
- Sticky navigation and mobile-optimized header
- Realtor section with agent bios
- Featured homes with photos and icons
- Testimonials section
- Call-to-action footer
